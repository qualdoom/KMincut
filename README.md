# Решение задачи $\mathsf{K-MINCUT}$ приближенно

Решение использует дерево Гомори-Ху для нахождения $k$-разреза, чей вес не превышает удвоенного веса минимального $k$-разреза.

Разные решения можно найти в папке `src/`, тесты можно найти в папке `tests/`.


Формат выходных данных:

```
n m k
u_1 v_1 cost_1
...
u_m v_m cost_m
```

Сборка проекта:

```
mkdir build && cd build
cmake ..
cmake --build .
./solution
```

Запустить тесты:

```
cd build && cmake .. && cmake --build . && ./unit_tests
```
